# /cbb-power-index

The command name is preserved for compatibility. Load `conference-strength` and title the result **Descriptive conference comparison**, not a power rating.

Read compatible standings and ranking observations. Show the available records, poll representation, explicit denominators and coverage gaps. Sorting by a named field is permitted; blending fields into an overall strength rank without a defined validated method is not. Do not infer schedule strength, selection likelihood or automatic bids from conference identity.
