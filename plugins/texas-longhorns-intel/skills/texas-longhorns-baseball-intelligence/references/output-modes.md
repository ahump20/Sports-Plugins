# Output modes

These are response formats, not hosted endpoints or automatic services. Each requires source observations, labeled interpretation and a recommendation whose strength matches the evidence.

| Mode | Shape |
|---|---|
| opsBriefing | Finding, small evidence table, gaps, next decision |
| internalMeeting | Decision, alternatives, evidence, tradeoffs, unresolved inputs |
| scoutingReport | Scope and sample, offense, pitching, defense where sourced, matchup uncertainties |
| editorialPiece | The writer's requested argument and voice, supported facts and attributed opinion |
| socialClip | Concise sourced copy with necessary date and scope; no automatic posting |
| hubContent | Structured blocks only against a supplied or inspected application schema |
| weeklyDigest | Explicit start/end dates, completed results, sourced changes, next games; one-time by default |
| pressConferencePrep | Source-grounded questions, follow-ups, facts to confirm; no invented quotes |

NIL and draft requests require actual public reporting. Distinguish reported compensation from estimates, and expert draft forecasts from selections. Without verified inputs and a documented method, numerical return-on-investment, projected-round or probability scoring is unavailable. An attractive matrix does not supply missing evidence.
